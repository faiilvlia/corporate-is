# Спецификация дизайн-системы «TERRA EXPEDITION» (TourHub RU)

> **Концепция:** Cinematic Exploration & Architectural Minimal  
> **Отраслевой контекст:** Платформа авторских экспедиций, треккинга и джип-туров по диким регионам России (Алтай, Байкал, Дагестан, Камчатка, Карелия).  
> **Архитектурный стандарт:** 3-уровневая модель W3C Design Tokens (Primitive → Semantic → Component).

---

Дизайн-система спроектирована на основе анализа предоставленных референсов мирового уровня (Awwwards):

| Референс | Ключевые паттерны, адаптированные в систему |

| **[Hiroto Sato](https://www.hirotos.com/)** | Строгая модульная сетка, японская чистота негативного пространства, технический моноширинный слой метаданных (`[01 // EXPEDITION]`, `[53.2° N]`). |
| **[Floema](https://www.floema.com/en)** | Тактильная природная палитра: оттенки горного травертина, известняка, базальта, землистая аутентичность. |
| **[Marvell Tile & Stone](https://www.marvellco.com.au/)** | Геометрическое благородство, монументальные акцидентные заголовки с открытой апертурой, ощущение фундаментальности. |

## 2. Цветовая палитра (Earth & Expedition Luxury)

### Базовая гамма (Obsidian Basalt)
* `--primitive-color-obsidian-950` (`#070809`): холст приложения, бездонная глубина.
* `--primitive-color-obsidian-900` (`#0D0F12`): фоновые секции и подложки.
* `--primitive-color-obsidian-850` (`#13161A`): базовые карточки туров.
* `--primitive-color-obsidian-800` (`#1A1E24`): активные и hover-состояния карточек.
* `--primitive-color-obsidian-500` (`#687383`): приглушённые подписи и моноширинные лейблы.
* `--primitive-color-obsidian-50` (`#F9FAFC`): чистый контрастный текст (снег Белухи).

### Природные акценты
* **Вулканическая Магма (`Magma` / Камчатка):**  
  `#E24F3A` — основной акцентный цвет для CTA, бронирования, активных индикаторов и бейджей статуса.
* **Реликтовая Тайга (`Taiga` / Алтай & Байкал):**  
  `#2A8772` — благородный хвойно-бирюзовый акцент для природных характеристик, сложности треккинга и эко-параметров.
* **Травертин & Песок (`Travertine`):**  
  `#F3EFE7` — тёплый минеральный оттенок для премиальных вторичных элементов и инверсных плашек.

## 3. Типографическая система (Editorial & Technical Harmony)

Система построена на диалоге трёх шрифтовых голосов:

1. **Display (Заголовки):** `Syne` / `Clash Display`  
   * Монументальный авангардный гротеск с широкими пропорциями и выразительным характером.
   * Применяется для Hero-слоганов, названий туров и титулов направлений.
2. **Body (Чтение):** `Plus Jakarta Sans` / `Inter`  
   * Высокая разборчивость, нейтральная геометрия, идеальный рендеринг при мелких кеглях.
   * Применяется для описаний маршрутов, отзывов и навигационных ссылок.
3. **Mono (Технический экспедиционный слой):** `JetBrains Mono` / `Space Mono`  
   * Чёткая эстетика экспедиционных журналов, технических паспортов и координат GPS.
   * Применяется для: дат, длительности, цен, размеров групп, тегов `[EXPEDITION // 07D]`.

## 4. Спецификации компонентов

### Карточка тура (`Expedition Tour Card`)
* **Поверхность:** `var(--component-tourCard-bg)` (`#13161A`).
* **Граница:** 1px `var(--semantic-color-borderHairline)` (`rgba(255, 255, 255, 0.07)`).
* **Скругление:** 16px (`--primitive-radius-lg`).
* **Hover-эффект:**
  * Граница плавно переходит в `rgba(255, 255, 255, 0.24)`.
  * Фоновое изображение плавно масштабируется (`transform: scale(1.04)` за 600ms `easeOutExpo`).
  * Тень усиливается до глубокого затемнения `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.
* **Технический оверлей:**
  * Верхняя панель: чип направления + моноширинная плашка длительности `[07 ДНЕЙ]`.
  * Нижняя панель: монументальный заголовок, цена в крупном кегле и статус доступности мест.

### Кнопки (`Action Buttons`)
* **Primary (Акцентная экспедиционная):**
  * Фон: `--semantic-color-accentPrimary` (`#E24F3A`).
  * Текст: Белый, полужирный.
  * Скругление: `full` (pill-shape).
  * Hover: сдвиг оттенка на `#FA6854` + мягкое неоновое свечение `box-shadow: 0 0 25px -3px rgba(226, 79, 58, 0.4)`.
* **Ghost (Архитектурная контурная):**
  * Фон: прозрачный.
  * Граница: 1px `var(--semantic-color-borderSubtle)`.
  * Текст: `--semantic-color-textPrimary`.
  * Hover: граница становится белой (`rgba(255, 255, 255, 0.6)`), фон окрашивается в `rgba(255, 255, 255, 0.05)`.

### Фильтры и капсулы направлений (`Destination Tabs`)
* Интерактивный ряд pill-кнопок:
  * Неактивная: прозрачный фон, тонкий hairline-бордер, приглушённый моно-текст.
  * Активная: тёплый травертиновый или обсидиановый плотный фон с контрастным текстом и светящейся точкой-индикатором.

## 5. Модульная сетка и ритм
* **Базовый шаг:** 4px / 8px.
* **Контейнер:** максимальная ширина `1360px` с боковыми отступами `32px` (desktop) и `16px` (mobile).
* **Сетка карточек:** адаптивная 12-колоночная сетка (3 колонки на десктопе, 2 на планшете, 1 на мобильном).
